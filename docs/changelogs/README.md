# Stowed changelogs

For a coordinated repository release, the finished section of the root `CHANGELOG.md`
is copied here as `CHANGELOG-<version>.md` (for example,
`CHANGELOG-0.1.0.md`). An independently versioned artifact uses
`CHANGELOG-<artifact>-<version>.md` instead. The root file is then reset to
`[Unreleased]` plus a pointer list.

History is never deleted — it only moves into this directory.
